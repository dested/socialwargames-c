# Decisions

ADR-lite, append-only. Newest first.

## 2026-08-09 — Poster chrome extends INTO the game (supersedes dark glass)
**Why:** after pulling the 3D rebuild, the user asked for the poster direction
to cover the game UI too. The diorama is sunlit — daylight paper chrome
harmonizes with it better than dark glass did. The holo data layer keeps its
glow (legibility law unchanged); only DOM chrome switched to paper.
**Rejected:** keeping dark-glass in-game with poster pages only (two visual
languages in one app); re-lighting the diorama to night to suit dark chrome.

## 2026-08-09 — Propaganda-poster theme for app chrome
**Why:** user rejected the plain starter chrome ("looks like dogshit"); of
three pitched directions (dark war-room, elevated warm war-table, propaganda
poster) the user explicitly picked **propaganda poster** — distinctive,
meme-able for a social faction game, works over either board art style.
**Shape:** aged paper + ink + hard offset shadows; Alfa Slab One / Oswald /
Special Elite; AI-generated no-text silkscreen posters (GPT Image 2) with type
set in CSS; game canvas palette untouched.
**Rejected:** dark command-bunker chrome; doubling down on the paper war-table
look; hand-drawn/Kenney-only art for the landing.
